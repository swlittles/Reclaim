# Security

Reclaim handles destructive local operations. Report suspected issues privately to the repository owner's established GitHub contact/security reporting channel before disclosing sensitive paths or reproduction data publicly. The repository is https://github.com/swlittles/Reclaim. Use its private vulnerability reporting option if enabled, or the owner’s established contact channel.

Include affected version, exact action, target type, preconditions, expected/actual outcomes and a synthetic fixture reproduction. Never include tokens, credentials, actual database contents or private code. Paths and Git/Docker tool output can be sensitive. See SAFETY.md for the threat boundaries and acknowledged filesystem races; do not represent those limits as strong atomicity guarantees.
