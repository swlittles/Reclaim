# Contributing

Run `bash scripts/test.sh` and `bash scripts/build.sh` on macOS. New destructive providers require exact target identity, review semantics, revalidation, documented recoverability, no privileged fallback, and fixture tests proving refusal cases. Scans must remain read-only, bounded, cancellable and honest about coverage. Do not test deletions on real user data. Keep Dev identity/update isolation intact. Preserve the MIT license and third-party attribution.
